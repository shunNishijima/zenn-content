# Web検索・取得の権限が許可されていないため、外部情報を取得できませんでした。ツール権限を許可いただければ再試行しますが、許可なしで進める場合、未検証の技術仕様

Web検索・取得の権限が許可されていないため、外部情報を取得できませんでした。ツール権限を許可いただければ再試行しますが、許可なしで進める場合、未検証の技術仕様や数値は記事に書けません(執筆ルールで「出典のない数値は書かない」と定められているため)。

どちらの方針で進めますか。

1. WebFetch/WebSearchの権限を許可していただき、Qiita記事などから事実を確認してから執筆する
2. 権限なしのまま、数値や具体仕様は「TBD」または「〜のようです」として、開発者が抱く疑問(プライバシー・オフライン動作・既存のOpenAI API連携ツールとの違いなど)を中心にした一般論寄りの記事として書く
