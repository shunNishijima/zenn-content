# AIっぽくない画像を作る画風プロンプトの選び方と使い方

**この記事の要点**

- 「AIっぽさ」は肌のツルツル感・過剰な被写界深度・左右対称構図など複数要因の重なりで生まれます
- 画風プロンプトはカメラ・フィルム・年代・技法を具体的に指定することで、AI特有の質感を回避する手法です
- 画風プロンプトは万能ではなく、テキスト情報が多い画像や正確な図解には向いていません

## なぜ生成AI画像は「AIっぽく」見えるのか

SNSで「これAIでしょ」と一瞬で見抜かれる画像には、共通する特徴があります。

肌が不自然にツルツルしている。被写界深度が浅すぎて背景が均一にボケている。顔や構図が左右対称すぎる。こうした傾向は、学習データに高品質・高解像度の画像が多く含まれることと関係していると考えられます。

さらに、プロンプトを指定しない場合のデフォルト出力は「無難で破綻のない絵」に寄りやすい傾向があります。これはモデルが平均的に「正解」とされやすい構図・質感を選びやすいためです。この「無難さ」こそが、AIっぽさの正体だと筆者は考えています。

つまりAIっぽさを消す作業は、モデルのデフォルト挙動から意図的に外れさせる作業といえます。画風プロンプトはそのための手段のひとつです。

## 画風プロンプトとは何か

画風プロンプトとは、写真の撮影機材・フィルムの種類・年代・技法などを具体的に指定する文言のことです。「高画質で」「リアルに」といった抽象的な指示ではなく、具体的な固有名詞や技術用語を使うのが特徴です。

たとえば以下のような要素を組み合わせます。

- カメラの種類（フィルムカメラ、コンパクトカメラなど）
- フィルムの粒子感（グレイン、ノイズ）
- 光の状態（逆光、フラッシュ撮影、蛍光灯の光）
- 年代を示す語（90年代、Y2K、昭和レトロ）
- 印刷・現像由来の劣化（色褪せ、スキャン跡、傷）

具体的な機材名を書くほど、モデルはその機材が持つ光学的なクセ（周辺減光、色収差、粒状感など）を再現しようとする傾向があります。抽象語より固有名詞のほうが効きやすい、というのが実際に触ってみた実感です。

### テンプレートの組み立て方

画風プロンプトは、以下の順番でパーツを組み立てるとテンプレート化しやすいです。

```
[被写体], [構図・アングル], [撮影機材/技法], [光の状態], [年代/質感], [色調]
```

例:

```
女性がカフェで本を読んでいる, 斜め上からのスナップ,
コンパクトフィルムカメラで撮影, 窓からの柔らかい逆光,
2000年代初頭の質感, 少し色褪せた色調
```

このテンプレートに沿って要素を差し替えるだけで、被写体を変えても一貫した「画風」を保てます。ポイントは、抽象的な形容詞（きれい、おしゃれ）をできるだけ具体的な名詞・技術語に置き換えることです。

## 画風プロンプトのカテゴリ分け

画風プロンプトは大きく4つに分類できます。検索してよく見かける38種類のような大量リストも、この4分類のどれかに属しています。

| カテゴリ | 具体例 | 効果の傾向 |
|---|---|---|
| フィルム・写真系 | フィルムグレイン、逆光、ハレーション | 粒状感とムラで均一さを崩す |
| 年代・カルチャー系 | Y2K、昭和レトロ、90年代広告 | 配色と構図の癖を再現する |
| イラスト・技法系 | 水彩、版画、コラージュ | 筆致のムラを出す |
| 劣化・ノイズ系 | スキャン跡、傷、色褪せ | 完璧すぎる質感を崩す |

複数カテゴリを組み合わせるほど「AIっぽさ」は減りますが、指示が増えすぎると意図しない破綻が起きやすくなる点には注意が必要です。3〜4要素程度に絞るのが扱いやすいと感じます。

## ネガティブプロンプトとの使い分け

Stable Diffusion系のツールでは、ネガティブプロンプト（生成してほしくない要素を指定する欄）を使えます。画風プロンプトとの役割の違いは以下の通りです。

- **画風プロンプト**: 「こうしたい」を積極的に指定する
- **ネガティブプロンプト**: 「こうなってほしくない」を除外する

たとえばネガティブプロンプトに「smooth skin, perfect symmetry, studio lighting」のような語を入れると、AIっぽい質感を抑制しやすくなります。ただしMidjourneyや一部のチャット型画像生成ツールはネガティブプロンプトの概念自体がなかったり、書式が異なったりします。使う前に、対象ツールが対応しているか確認しておく必要があります。

## ツールによる違い

画風プロンプトの効き方はツールによって差があります。

- **Stable Diffusion系**: プロンプトの語順や重み付け記法が結果に強く影響しやすい
- **Midjourney**: 独自パラメータ（バージョンやスタイル強度の指定）と組み合わせて使う設計
- **ChatGPT・Gemini等の対話型画像生成**: 自然文での指示に強く、機材名より状況描写が効きやすい印象

同じプロンプト文をそのまま使い回しても、ツールが変われば出力の傾向は変わります。ツールごとに軽くチューニングし直す前提で使うのが現実的です。

## デメリット・向いていない人

画風プロンプトには限界もあります。

- **テキストを含む画像**: ロゴや文字入りバナーなど、正確な文字表現が必要な用途には向きません。画風を強めるほど文字が崩れやすくなります
- **精密な図解・技術資料**: 回路図やUML図のような正確性が求められる画像は、画風プロンプトの対象外と考えたほうがよいです
- **毎回同じ結果が欲しい人**: 画風プロンプトは乱数の影響を受けやすく、同一プロンプトでも仕上がりが揺れます。再現性を重視する用途には不向きです
- **著作権・商用利用を厳密に管理したい人**: 特定の作家名やブランド名を画風指定に含めると、権利面のリスクが生じる可能性があります。実在する作家名を直接指定するのは避け、技法名や年代・機材名で表現するほうが安全です

「AIっぽさを消したい」という目的が先にあり、写真としての正確性や再現性が二の次でよい用途に向いた手法だといえます。

## よくある質問

**Q. 画風プロンプトを使えば必ずAIっぽさは消えますか？**
完全には消えません。学習データやモデルの基本特性に由来する傾向は残るため、あくまで軽減する手法だと捉えるのが妥当です。

**Q. ネガティブプロンプトだけでも十分ですか？**
除外指定だけでは方向性が定まらず、無難な出力に戻りやすいです。画風プロンプトと併用するほうが狙った質感に近づきます。

**Q. 何個くらい要素を組み合わせればいいですか？**
3〜4要素程度が扱いやすい目安です。増やしすぎると指示同士が矛盾し、構図が破綻しやすくなります。

**Q. Midjourneyでもフィルムカメラ系のプロンプトは効きますか？**
効く傾向はありますが、Stable Diffusion系ほど語順や重み付けの影響は大きくない印象です。ツールのパラメータと併用するのが基本です。

**Q. 実在の写真家やイラストレーターの名前を入れてもいいですか？**
権利面のリスクがあるため避けたほうが無難です。技法名・年代・機材名など、固有の個人名に依存しない表現に置き換えることをおすすめします。

**Q. 商用利用する場合に気をつけることは？**
生成物の利用規約は各ツールで異なります。実際の利用前には、使用するツールの最新の利用規約を必ず確認してください。

**Q. イラスト系の画風とフィルム写真系、どちらから試すべきですか？**
作りたい最終イメージに近いカテゴリから試すのが早道です。写真的な質感が目的ならフィルム・写真系、絵柄の個性を出したいならイラスト・技法系から着手するとよいです。

次に試すなら、自分がよく生成する被写体ジャンル（人物、風景、プロダクトなど）ごとにテンプレートを1つずつ作り、要素を1個ずつ増減させて効き方の違いを検証してみることをおすすめします。
